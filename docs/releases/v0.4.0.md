# ATHLTH Home Assistant v0.4.0

This release introduces the new ATHLTH-branded Home Assistant experience, available as both an all-in-one dashboard and modular Lovelace cards.

## What's new

- Premium light ATHLTH dashboard with original pulse-A logo, warm-gold accents, responsive layout and optional family member switching
- New independent cards for online/training status, calendar, planned workouts, goals, recovery, recent workouts, strength and active sessions
- Privacy-aware **Online**, **Trener nå**, **Offline**, **Ukjent** and **Ikke delt** presence states per paired app installation
- Freshness expiration after four minutes: an old "Trener nå" state can no longer remain live indefinitely
- Family overview with per-member status colors and current online/training counts
- Active training-plan metadata, calendar session state, and plan progress when the connected ATHLTH app shares them
- Last-workout detail adapted to strength, treadmill or outdoor training; outdoor route map only when the timestamps match the completed workout
- Limited received-workout history: up to ten completed events received **after pairing**, not a complete historical import
- Safer data-clearing behavior when sharing is revoked, with isolated data for each installation
- More regression tests for frontend rendering, state freshness, pairing security and Home Assistant HTTP serving

## Requirements and how to install

- Home Assistant **2026.9.4** or later and HACS with the [ATHLTH_HA integration](https://github.com/Wesc-9/ATHLTH_HA)
- Update **ATHLTH** in HACS, then **restart Home Assistant**
- Add **ATHLTH** from Settings → Devices & services and pair using the ATHLTH iPhone app, or keep your existing pairing
- Add **`custom:athlth-dashboard-card`** to an HA dashboard; [working YAML example](https://github.com/Wesc-9/ATHLTH_HA/blob/main/examples/premium-dashboard.yaml)
- The bundled JavaScript registers automatically. If it does not appear, check the Lovelace resource **`/athlth/frontend/athlth-cards.js`** (type: JavaScript module) and reload the browser; avoid duplicate entries
- Each user must opt into the relevant data sharing in ATHLTH. Online sharing is optional and off by default.

## Important limitations

- The full end-to-end setup has **not** been verified on a real HA instance with iPhone and Apple Watch. Automated checks include HA 2026.9.4 and 2026.10 beta, frontend, privacy, Hassfest and HACS validation.
- Online means *the paired app installation is foregrounded and recently synchronized*, **not** verified ATHLTH social-network presence. Offline/private/stale statuses remain distinguishable.
- Family membership is per installation, not yet a fully verified cross-device ATHLTH account identity. Only consented data should be shared with a household dashboard.
- Training-plan structure, sets, long-term workout history and retrospective backfill are not yet fully exported.
- Previously stored Home Assistant Recorder data can remain after sharing is revoked and may require separate HA history cleanup.
