# ATHLTH Home Assistant v0.5.1 — iPad layout and scroll stability

This release fixes two Home Assistant iPad app issues reported with the
Training Intelligence dashboard in v0.5.0.

## Fixes

- **No more jump to the top while scrolling:** Home Assistant sends updated
  `hass` objects frequently, including for unrelated sensors. Previously the
  frontend rewrote the entire dashboard Shadow DOM on every update. v0.5.1
  keeps the existing DOM tree and updates only changed nodes, protecting the
  scroll position, images and card controls.
- **Better iPad width support:** Home Assistant Sections views can now place
  the ATHLTH combined dashboard across all 12 grid columns using the
  `getGridOptions()` custom-card API.
- **More responsive multi-column grid:** at least 790 CSS pixels of actual
  card width gives three columns; 620–789 pixels gives two; narrower windows
  adapt to a single column. The inner grid cannot overcome a narrow
  Home Assistant Masonry column.
- **Self-diagnosis for a constrained card:** when displayed in a large iPad
  viewport but forced inside a narrow HA column, the dashboard shows a short
  instruction to use a Panel view or a full-width Sections tile.
- Regression coverage for full-width grid settings, irrelevant sensor
  updates, preserving existing DOM references and patching updated content
  without replacing the main scroll tree.

## Important: Dashboard layout setup

**For an existing dashboard that still shows just one card across:**

1. In Home Assistant, open the ATHLTH dashboard.
2. Edit the **view** containing `custom:athlth-dashboard-card`.
3. Select **Panel (one card)** for that view, and leave the combined ATHLTH
   dashboard as its single outer card. The ATHLTH card itself then arranges
   several smaller cards in two/three columns.
4. Alternatively, in a **Sections** view place the ATHLTH dashboard card
   at full width (12 columns). The new card supplies this width preference.
5. If you are editing raw YAML, the working example uses
   `panel: true` under the ATHLTH view:
   [premium-dashboard.yaml](https://github.com/Wesc-9/ATHLTH_HA/blob/main/examples/premium-dashboard.yaml).

The word **Panel** here refers to an HA view with one *outer* card, which
contains the entire ATHLTH grid. It does **not** mean ATHLTH will display just
one metric card.

After installing **v0.5.1** from HACS, restart Home Assistant and fully
close/reopen the iPad app once to clear its cached dashboard JavaScript.

## Compatibility / safety

- Requires Home Assistant 2026.9.4 or later.
- Maintains the existing ATHLTH data protocol and v0.5.0 profile / record
  sharing controls. Does not change consent settings or publish new data.
- Automated release checks validate the frontend, supported Home Assistant
  versions, security/privacy, HACS and Hassfest before a GitHub release.
- iPad simulator or physical Home Assistant app testing remains necessary
  for final device-level confirmation.
- This Home Assistant release does not trigger ATHLTH iOS TestFlight.
