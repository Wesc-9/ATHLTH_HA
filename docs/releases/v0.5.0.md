# ATHLTH Home Assistant v0.5.0 — Training Intelligence

A broader ATHLTH training overview, including a real recent-workout list,
progress visualizations, tomorrow's training and opt-in athlete achievements.

## What's new

- Refined **ATHLTH Training Intelligence** dashboard with an editorial dark
  performance header, premium light analytics, warm-gold accents, responsive
  three-column desktop layout and limited logo repetition
- Featured **last completed workout** with route thumbnail only when a real,
  properly matched outdoor map is available
- **Recently completed workouts** in chronological order with actual
  date, workout category, duration, distance, and other received metrics;
  records are marked as received, not a complete archive
- **Tomorrow's workout** from dated calendar/next-workout information, plus
  the training plan, weekly progress, workout schedule and goals
- **Seven-day training duration chart**, distribution of received activity
  categories and visual weekly completion rhythm
- New opt-in **athlete identity**: display name and public ATHLTH profile
  image; not enabled by default
- New opt-in **personal-record snapshots**: up to 12 actual running/strength
  achievements available in the ATHLTH app, displayed as premium record tiles
- Improved data-source coverage, consent withdrawal, bounded retention
  and per-paired-device identity isolation
- Backward-compatible extension: the mobile app sends athlete profile and
  performance snapshot fields only after the HA integration advertises
  `profile_performance_snapshot_v1`
- Expanded automated frontend, data validation, privacy and persistence tests

## Installation

1. In **HACS → ATHLTH**, update to **v0.5.0** once the release is listed.
   If ATHLTH is not found by name, add the custom integration repository
   `https://github.com/Wesc-9/ATHLTH_HA` in HACS.
2. **Restart Home Assistant** after the integration update.
3. Keep the existing ATHLTH device pairing, or pair ATHLTH from
   Settings → Devices & services if new.
4. Open the ATHLTH dashboard with one full-width (Panel) view using
   [`examples/premium-dashboard.yaml`](https://github.com/Wesc-9/ATHLTH_HA/blob/main/examples/premium-dashboard.yaml).
5. Reload the browser if the updated frontend does not appear. The included
   `/athlth/frontend/athlth-cards.js` resource should not be added twice.
6. In the **ATHLTH iPhone app → Home Assistant settings**, turn on
   **Utøverprofil** and/or **PR-er og milepæler** only if you want those
   categories shared. The version of the iPhone app must include
   the corresponding snapshot code; a Home Assistant update alone cannot
   create profile images or personal records.

## Data and privacy boundaries

- Only ten completed workout events are stored per paired installation by
  this integration; the dashboard does **not** claim historical import.
- Full training history, interval splits, multi-week Health trends and
  exercise-specific progressive overload require a future protocol change.
- Workout routes are shown only if shared as a map image and the last
  outdoor workout's completion time matches the image.
- The dashboard cannot infer running pace PRs, 4×4 records, or personal
  bests without records provided by the ATHLTH app.
- Revoking athlete profile or PR sharing clears the **current** HA state and
  persisted ATHLTH integration data; historical Home Assistant Recorder
  entries may require a separate user-initiated history purge.
- Public profile photos come from the ATHLTH public avatar storage URL.
  Users of a shared HA dashboard may see these photos and other shared data.

## Compatibility and validation

- Home Assistant: **2026.9.4** or later
- Integration manifest: **0.5.0**, protocol: v1 with optional feature
  negotiation for profile/PR snapshots
- GitHub release automation runs automated Python tests on supported HA
  versions, JavaScript regression tests, privacy checks, Hassfest and HACS
  validation **before** publishing the tag.
- Manual end-to-end testing on real Home Assistant, iPhone and Apple Watch
  hardware is **not yet confirmed**. No TestFlight build or App Store
  publication is triggered by this Home Assistant release.
- The repository is public and can be added as a **custom repository** in
  HACS, but this GitHub release does not by itself add ATHLTH_HA to the
  official HACS default catalog.
